Trolley Launch - installable app version

Upload all of these files together to any free static host
(Netlify Drop, GitHub Pages, Cloudflare Pages). Open the link on
your phone, then:
  Android (Chrome): menu > Install app / Add to Home screen
  iPhone (Safari): Share > Add to Home Screen
It installs as "Trolley Launch" with its own icon, runs full screen,
and works offline after the first visit. WhatsApp shares will include
the link to your hosted game.
